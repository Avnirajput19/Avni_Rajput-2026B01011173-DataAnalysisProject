# Avni_Rajput-2026B01011173-DataAnalysisProject
Titanic Dataset – Data Cleaning and Exploratory Data Analysis using Pandas

# Project Overview

This project focuses on understanding and analysing the Titanic dataset using Python and the Pandas library. It involves basic data cleaning, data manipulation, and Exploratory Data Analysis (EDA) to understand the dataset and identify useful patterns.

The project is created as a beginner-level practice project to understand how real-world datasets can be handled using Python.

# Objectives

- Load and explore a CSV dataset using Pandas.
- Understand the structure and information of the dataset.
- Identify missing and duplicate values.
- Perform basic data cleaning.
- Select and analyse specific columns.
- Apply basic Exploratory Data Analysis (EDA) commands.

# Technologies Used

- Python
- Pandas
- Jupyter Notebook
- Kaggle (to download data)

# Dataset

The project uses the Titanic Dataset ("Titanic-Dataset.csv"), which contains information about passengers aboard the Titanic.

Some of the important columns include:

- PassengerId
- Survived
- Pclass
- Name
- Sex
- Age
- SibSp
- Parch
- Ticket
- Fare
- Cabin
- Embarked

# Operations Performed

1. Data Loading

- Imported the Pandas library.
- Loaded the CSV file into a DataFrame.

2. Data Exploration

- Displayed the first and last few rows.
- Checked the number of rows and columns.
- Examined column names and data types.
- Generated statistical summaries.

3. Data Cleaning

- Identified missing values.
- Checked for duplicate records.
- Removed null values from the Age column.
- Worked with selected columns for better data analysis.

4. Exploratory Data Analysis (EDA)

- Checked unique values in columns.
- Analysed passenger information.
- Used basic Pandas functions to understand the dataset.
